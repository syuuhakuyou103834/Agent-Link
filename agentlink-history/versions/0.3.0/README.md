# AgentLink GUI 0.3.0

这是基于 PyQt5 的双机 Codex 协作程序。应用内置 Python 3.13，Windows 10/11 x64 可直接安装，不需要安装 pip 包。每台电脑仍需有已登录、支持 App Server 的 Codex。本版按本机 Codex 0.153.4 协议开发。

## 使用

1. 两台电脑都关闭旧版 AgentLink 接收脚本，然后分别运行 `AgentLink-GUI-Setup.exe`。
2. ZHOUBY 选择 A；WILLDESKTOP 选择 B。安装完成打开桌面“AgentLink GUI”。
3. 首次设置默认共享目录为 `\\192.168.1.108\shared\AgentLink-GUI-v1`。两边必须一致。程序不保存 SMB 密码；沿用当前 Windows 用户已建立的共享访问。
4. 检查自动找到的 `codex.exe`，保持“沿用本机 Codex 技能和插件配置”和“只读沙盒”，保存后点“连接节点”。
5. 两边在线后，任一台输入议题、选评审轮数、点“发起讨论”。1 轮为初稿→评审→修订，共 3 次调用；2 轮为 5 次调用。双方都能暂停、继续、停止和补充要求。

两台共同处理一场讨论。发起方负责初稿与最终修订，另一方评审。暂停在当前调用结束后生效；停止请求中断正在运行的模型，接口不响应时终止本机 App Server 进程树。失败后保留记录，不自动重发模型请求；新建讨论后可再次尝试。

## 界面

- 讨论现场分 A/B 两列，增量显示回答；对方内容约每秒同步。
- 公开思考摘要只显示接口提供的摘要，不显示完整内部思考。接口未提供时该页留有说明。
- 工具事件显示命令、工具状态和有限长度的输出；原始接口诊断在本机日志。
- 节点能力来自各台 Codex 的技能与 MCP 服务清单；实际可用性仍取决于配置、授权和当前项目。
- 本机项目目录影响项目技能/规则。各台自行选择目录与权限，另一台不能远程提高权限。只读不等于禁用全部外部工具；额外权限请求不会自动批准。
- 用户输入请求暂以运行日志提示，可用“补充到下一轮”传达要求；本版不提供通用工具授权弹窗。
- 导入旧版 `discussion.txt` 可阅读既有记录；导出完整记录为 TXT/Markdown。“实施交接”只生成交接文档，后续在具体项目中执行。

## Codex 桌面界面

本版通过 Codex 本地 App Server 创建各节点独立、非临时的任务，同一节点在一场讨论中复用任务。可复制“Codex 任务 ID”，在对应电脑的 Codex 桌面端请助手打开该本机任务。任务是否直接出现在侧栏取决于桌面端版本和项目列表；本版不修改 Codex 数据库。跨两个账号的完整讨论由 AgentLink 界面汇总，并非原生跨账号群聊。

官方接口说明：https://learn.chatgpt.com/docs/app-server

## 文件与卸载

- 程序：`%LOCALAPPDATA%\Programs\AgentLinkGUI`
- 设置、历史、日志：`%LOCALAPPDATA%\AgentLinkGUI`
- 旧版本：`%LOCALAPPDATA%\AgentLinkApp`，本版保留。
- 共享记录：所选共享目录下 `jobs`；节点在线状态在 `nodes`。
- 完整源码直接包含在安装目录的 `main.py`、`app`、`source`，运行环境是普通文件，可检查、修改和替换。
- 卸载：关闭程序，删除“AgentLink GUI”桌面/开始菜单快捷方式和上述程序目录。历史目录可保留。

安装程序为本地构建的未签名文件，按当前用户安装，不要求管理员权限。不复制任何 Codex 登录凭据到共享目录或安装包。代码使用 GPL-3.0；依赖许可及源码获取地址见 `licenses`。

## 验证范围

源码中 `tests/test_system.py` 使用本机两个独立模拟 App Server，验证 A/B 均能发起、多轮、中文、流式事件、跨节点暂停/继续/停止、故障传递与重复执行保护。模拟测试不消耗模型额度。本版打包后还验证内置 Python/PyQt 启动和界面渲染。新的 GUI 在真实两台电脑和各自账号下的联调，仍需安装后完成；旧版本已经通过用户的真实双机验证。
