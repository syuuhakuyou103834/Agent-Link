# AgentLink 0.3.11 · 项目源码交付与独立审查

本版增加“项目代码审查”，保留 0.3.10 的文字讨论、双向发起、暂停/补充/停止、上下文续接、历史、导出和任务 ID 功能。旧版目录与配置没有被本次构建覆盖。

## 使用方法

1. 两台电脑均使用本版，保持原有 B 端共享通信目录。局域网工作不依赖 GitHub。
2. A 打开“管理项目”，输入项目名称、选择实际源码目录并保存。可为任意项目建立独立绑定；不要求 Git。
3. B 连接同一共享目录后切换到“项目代码审查”，可选择 A 发布的项目。默认自动建立本机快照目录；也可在“管理项目”指定接收根目录。
4. 如需本机 Python/虚拟环境等额外依赖，在项目管理中逐个声明只读路径。不得选整盘。找不到依赖会报告阻塞，不自动扩大访问范围。
5. 选择项目，填写范围明确的任务，点击发起。默认 3 对实施/审查加 1 次只读总结，共最多 7 次 AgentLink 顶层请求。双方都可发起，A 始终修改代码，B 始终审查。

## 每轮行为

- A 实施并运行相关测试，模型进程结束后，应用扫描和交付完整的项目文件快照。包括未跟踪的新文件、测试、配置、资源和空目录。
- 打包前后核对项目，生成文件哈希、变化清单、排除清单、场次/项目/修订编号，最后发布 ready 记录。单项目上限 100000 个条目、4 GiB；超限阻塞，不截断。
- 默认排除 .git/.svn、依赖缓存、Python 字节码和常见凭据文件（包括 .env*、私钥）。目录不会按 Git ignore 自动排除。排除项有记录；这属于文件名规则，不保证识别所有秘密。请勿把不应交付的秘密写入普通源码。
- 不跟随符号链接、目录联接、重解析点或硬链接；需要相关依赖时须明确整理或声明。跨项目路径不随源码交付。
- B 从本机已校验的 ZIP 解包，在项目/场次/哈希对应的目录中读取固定快照。源码及已有测试只读；新增测试、日志和缓存写入独立 project-tests 目录。原项目内容不会通过网络挂载给 B，也不会开放 A 的软件。
- B 输出结构化审查：快照哈希、结论、实际阅读路径、测试命令及结果、未验证事项和无关问题。收到了全项目不等于阅读了全项目。
- B 通过或阻塞会提前转入 A 总结；只有 B 通过且 A 最终明确同意，才显示审查通过；持续要求修改则最多用完设定轮次。最后一轮修改仍须由 B 评审。A 总结使用新建的只读会话，之后再次核对项目是否变化。
- “流程已完成”与“审查通过”分开显示；未达成一致时需用户裁决。无关问题保存到共享 projects/<项目ID>/issues.json，不自动增加修改任务。

## 权限与兼容性

项目模式使用 Codex 的命名权限配置（experimental App Server API）：只允许所选源码、独立测试目录以及明确声明的依赖和最小系统运行库。命令网络关闭，追加审批拒绝，不提供完全访问或自动审批选项。项目会话禁用已配置 MCP/插件和 Web 搜索，避免外部工具越过文件边界。文字讨论继续使用原节点设置。

若 Codex 无法确认配置或操作系统沙盒不能实施读取限制，会在模型请求发出前阻塞。不能用旧的 read-only/workspace-write 模式替代这一检查。2026-09-11 本机 App Server 实测拒绝了受限令牌沙盒下的分离读取权限，详见 DEBUG-0.3.11.md；因此本版为待真实双机验收的候选版本。

## 证据位置

- 本机项目配置：数据目录/projects.json（绝不以对端文本绑定 A 的本机路径）。
- 共享目录/jobs/<场次>/artifacts/<哈希>/：source.zip、manifest.json、ready.json。
- 本机 runs/<场次>/*-scope.json 和 manifest-*.json：实际路径与清单。
- 共享场次 call-*.json：请求发送前占位及结果接收状态，绑定角色/阶段/请求尝试；send_pending 表示可能已发出，禁止自动重发。
- review-<轮>.json、turn-*.json、report.json：审查、模型结果和验收结论。

文件传输、哈希和普通测试不调用模型；7 次预算不统计模型内部工具动作，也不能证明服务端执行恰好一次。真实模型测试未在本次开发中运行。

## 启动及回归

便携版运行 AgentLink.exe；源码运行 `python main.py`。使用 `--data-dir <独立目录>` 可隔离配置/历史。项目管理和 GUI 依赖 PyQt5，便携包自带运行库。源码运行 `python tests/run_release_checks.py`；结果保存在 source 的上级 evidence 目录。

本机模拟和 Qt 检查不能代替 B 真实电脑、SMB 中断或操作系统权限验收。历史 0.3.4、0.3.9 和 0.3.10 原包仍保留。
