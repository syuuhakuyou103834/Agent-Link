# 0.3.6 候选的兼容与验收边界

本次修复能力记录过期、离线、角色锁已释放以及对端重启换实例时仍被准入的问题。使用 agentlink-live-instance-v2；检查心跳时效（12 秒内、最多容忍对端快 1 秒）、角色锁归属记录与锁持有情况，将双方实例绑定到场次，并在排队执行、发送前和结果发布前复查。时钟偏差过大会保守拒绝；尚未完成真实双机时钟与休眠验收。

检查与请求发送之间不具备原子握手：对端在最后检查通过后退出，仍可能已经消耗一次请求。此时阻止后续推进，保留错误和结果核查线索，不自动重发。

两端须使用 0.3.6 或声明并实现同一协议能力的版本。0.3.5 与 0.3.6 双向拒绝、零请求；未修补的 0.3.4 发起时仍可能先发送一次初稿。旧版不得参与同一正式会话；这一使用限制不代表旧版混用验收通过。

补充编号在同一场次内全局唯一：同编号同内容仅应用一次，同编号不同内容明确冲突；不同编号相同内容均保留。不同场次复用编号互不影响。GUI 为每个新操作生成 UUID；两端编号碰撞遵守相同冲突规则。

本轮 59 个本机自动化用例通过，包含能力时效和编号碰撞；故障恢复 12 对共 48 次模拟请求。故障以模拟接口和文件发布异常注入，不能替代硬终止进程、真实 SMB 中断或实际权限隔离。原 110 场正常耐久属于 0.3.4 的历史运行，不转记为本候选的耐久结果。完整日志和证据对应表见候选工作目录 REVIEW-RESULTS.md。
