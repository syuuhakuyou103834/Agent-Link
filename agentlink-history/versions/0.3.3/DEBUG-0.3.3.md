# AgentLink 0.3.3 修复说明

修复源自 0.3.2 的 T08、T17、T18 本机测试。双方应使用相同修复版本；真实双机 SMB、断网恢复及混合版本安全性尚未验收。

- T18：任务和步骤协议只接受严格整数 1。有效时间只接受非布尔有限数值，并检查过期。非法数据在领取步骤及模型请求前拒绝。
- T08：本机发起槽在提交时保留；执行中和待处理时的重复提交立即提示冲突，不排队。服务线程取得共享 discussion.lease 后才接受请求，直到执行结束持有锁。显式 request_id 在共享 start-requests 中留存，重启后重放同一编号不会再次执行；已接收但未完成的编号也不自动重试。GUI 线程不执行共享文件操作。
- T17：停止、结果发布、终态提交和错误发布共用每场 lifecycle 锁。首先提交的终态保持不变；迟到流和结果检查原场次归属与终态。停止已提交时不保存迟到完成结果。底层 Mailbox.put 仍是原始存储接口，终态保证位于服务调用链，不能用于约束任意旧版或外部写入者。

本包保留各节点原有权限、登录与默认数据目录设置。测试使用隔离目录和离线模拟接口。start-requests 只记录请求编号、节点、实例和接受时间，不含凭据。

本次未实现共享中断后的自动结果补发、崩溃后的旧执行者隔离或完整协议协商；这些属于尚未完成的 T11、T12、T18 验收范围。
