# AgentLink 0.3.10 整合交付

2026-09-11，节点 A。以冻结 0.3.9 的源码为基础恢复 0.3.4 的有用功能。本次完成本机代码整合、回归、构建及本地交付，不替代真实双机验收。

## 恢复与保留

- 恢复无时限任务等待：不再用 900 秒调用时限、90 秒 turn/start 响应时限、20 分钟等待对方时限或整场 expires 终止正常长任务；新讨论使用 protocol=2、expires=null。
- 恢复本机和对端的执行活动显示，包括运行时长、最近事件、工具执行中及静默但进程仍在的提示。旧轮次事件不能刷新新轮次活动时间。
- 恢复未完成讨论的部分公开输出、明确的“未完成输出”标记及对应本机任务 ID 导出。
- 兼容协议 1 和 0.3.4 的协议 2 已完成历史；继续讨论不会改写原始历史。由实际 0.3.4 Settings.save/Mailbox.create 生成的样本随源码附带。
- 修复 timeout_seconds=0 的配置加载问题；旧 0/900/3600 等值迁移为无时限，角色、项目目录、模型、沙盒、工具模式等其余字段保持。
- 保留 0.3.9 的 Windows Job 进程归属、共享执行锁、清理失败留存句柄、实例绑定、角色锁及时效校验、旧事件隔离、步骤与结果校验、补充去重、暂停发送边界和分块读取。
- 新能力标志 agentlink-execution-lease-v4：需双方使用 0.3.10 或兼容实现。旧版本可以提供已完成历史，不能参与该版的新活动讨论。

另修复整合时发现的快速切换竞态：前一场已经结束而心跳尚未更新时，不再误报“对方已切换场次”；接收新场次立即更新心跳。真正指向另一场非终态讨论时仍拒绝继续。
