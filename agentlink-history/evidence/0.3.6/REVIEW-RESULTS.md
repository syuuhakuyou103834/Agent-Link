## 修复的具体边界

新协议能力为 `agentlink-live-instance-v2`。对端心跳必须为有限数值、12 秒内且最多容忍快 1 秒；角色、实例、归属记录和正在持有的角色锁须一致。场次绑定双方实例，排队启动不能重新绑定已重启的对端。对端变化时停止自动推进，禁止重发。仍存在检查与发送之间的时间窗口；这不是原子双机握手，也未证明真实 SMB 锁语义或完整时钟偏差/休眠行为。

补充 ID 为同一场次内的全局事件标识，跨节点碰撞不按文本吞并：同 ID 异文明确冲突，同文认为同一事件重投；合法重复文本使用不同 ID，GUI 新操作生成 UUID。跨场同 ID 独立。此轮无需修改已存在的 0.3.5 去重逻辑。
