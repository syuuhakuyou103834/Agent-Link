## 真实环境阻塞

本机 Codex 在 thread/start 阶段返回：

```
windows unelevated restricted-token sandbox cannot enforce split filesystem read restrictions directly; refusing to run unsandboxed
```

当前受限令牌 Windows 沙盒不能实施所需的分离读取权限。程序保留阻塞，没有改成更宽权限、创建管理员授权、改变系统 ACL 或自动审批。配置返回值/模拟响应不能证明 OS 拒绝越界访问；本次真实检查也不能算权限隔离通过。

因此真实项目模式仍需两机各自具备并核验支持项目读取隔离的 Codex 环境，然后再做 A/B 双向场次、只读源码写入拒绝、范围外读取拒绝和实际 SMB 故障验收。源码/包已可供检查，但不应把本报告理解为这部分已完成。

源码交付是固定副本，不开放 A 的其他路径或软件。其他桌面程序/用户仍可修改 A 源码，应用在交接和总结时检查是否与已审查快照一致；这不是对整台机器所有进程加文件锁。凭据排除使用文件名规则，不保证发现普通源码中硬编码的秘密。

完整使用说明在交付目录 README.md；权限边界和排错在 DEBUG-0.3.11.md。逐项机器结果在 C:\AgentLink-project-review-0.3.11\FINAL-RESULTS.json。
