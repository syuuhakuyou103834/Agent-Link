# AgentLink 0.3.15：定向输入与项目中断恢复

日期：2026-09-11。用户确认：人工恢复未完成步骤，完成后接回原 A/B 流程，不重跑已完成 A 步骤。

## 使用

两端关闭旧 AgentLink 后使用 0.3.15，连接同一共享目录。保留原数据目录、项目绑定和 Codex 账号。无需新建源码项目。

运行中打开“节点对话与恢复”，选择 A 或 B，填写要求并点击“发送给该节点”。有正在运行的请求时使用 turn/steer；目标暂未执行时保留到该节点下一次请求。输入仅送入目标节点，双方均可见审计记录，不是私密聊天。回执区分排队、发送中、送达、拒绝、不确定；没有收到确认不会自动重发。

额度或环境恢复后，在历史中选择失败的项目场次，在“节点对话与恢复”选择未完成步骤所属节点，输入例如“额度已恢复，请核查已有检查和文件后继续未完成步骤”，点击“恢复该节点并继续流程”。恢复新增请求，旧失败场次保留；新关联场次承接已完成步骤及快照，未完成节点使用 thread/resume 继续原会话，成功后接回 A/B 流程。例：A 已完成、B 失败，恢复只调用 B，再调用 A 总结；不会重跑 A 初稿。多次失败请选择最新恢复场次。

## 保存与校验

- 输入绑定场次、目标实例和消息 ID；重复 ID 不重复发送；turn/steer 绑定 expectedTurnId，不能误送另一请求。
- 项目调用失败保存最新公开输出及错误、原会话 ID、步骤请求、源码快照和本机范围；不把部分输出判为完成。
- 原失败 state/turn 文件不改；新场次记录 recovery 来源及累计请求尝试，旧场次新增 recovery-child 回链。计数包含失败尝试，不能按完成消息数推算真实计费。
- 恢复重新获取讨论和执行权、绑定两端当前实例，校验本机范围、原会话归属和快照，重新确认权限。B 服务重启可恢复；原会话已删除、路径变更、快照修改或缺少记录则阻塞，无新会话兜底或自动重试。
- 停止和完成场次不会被恢复按钮复活；恢复仅适用于项目代码审查。文字讨论支持定向输入，但不支持本版项目恢复流程。
- 不自动查询或消耗额度重置，不绕过账号额度，不放宽项目权限。截图的进程退出不能单凭界面归因为额度耗尽；原始错误保留。
