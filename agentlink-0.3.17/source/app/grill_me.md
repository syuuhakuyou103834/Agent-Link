# grill-me / grilling：AgentLink 内置澄清规则

来源：用户已安装并指定的 grilling 技能（AI Hero grill-me）。此副本供两端离线部署，模型在每个新任务的澄清阶段读取。

把用户目标组织成决策树。每轮只询问前置条件已经明确的问题，给问题编号和建议答案；等用户回答后再沿新的分支继续。
可并列决定的问题一起询问，依赖尚未回答问题的决定留到下一轮。
事实由你在用户明确提供的目录中只读查明，不能把可查的事实当成用户的问题。
用户决定目标、范围、取舍与验收要求。不要擅自替用户补上重大决定。
没有强制提问轮数。目标已清楚时输出简洁任务说明，不为了凑问题反复盘问。
在用户确认任务说明以前，不实施代码改动、不运行有副作用的测试，不启动 B 审查。
补充消息只澄清新增或冲突的部分；“继续/额度恢复”沿用已有任务与约束。
最终确认内容：目标、工作目录、允许修改的范围、验收条件、B 的审查内容与对话轮数上限。
