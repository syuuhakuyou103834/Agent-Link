## 实现与修复

- 新增 `app/conversation.py` 持久对话、结构化任务说明、说明哈希绑定确认、A/B 调度、定向补充、请求尝试记录和恢复投影；新增 `app/ui_conversation.py`，公共界面组件放入 `ui_support.py`。
- `engine.py` 接入统一调度，阻止 B 新建任务；主动关闭 App Server 后不再继续轮询已关闭进程，避免误报意外退出。
- `review_workflow.py` 按确认的讨论/审查/修改行为配置权限；无目录的新任务重置读取范围，不继承旧项目的访问权限。
- 只读聊天流式落盘节流，无变化的对话不重复写入共享目录；本机初次 11 项新流程测试用时约 263 秒，后续约 68 秒。测试夹具同期有调整，这不是受控性能基准。
- 暂停后的“继续”在控制入口解除暂停，避免等待模型预检线程形成死锁；输入持久化回执到达才清空输入框；终态和迟到事件保留保护。
- **确认的存储缺陷**：两个节点首次创建同一锁文件时，旧顺序在取得字节锁前写入/flush，可与另一句柄的锁竞争并触发 `PermissionError errno=13`。现改为先加锁再初始化；保留稳定侧文件和旧值保护。测试重现旧顺序并验证并发新顺序。
- 请求状态不确定时不自动重发；明确恢复沿用原节点会话和可证明的本机范围，恢复场次关联原失败记录。

## 已知限制与后续验收

1. 实现和模拟覆盖完成不代表真实模型语义判断已经通过。真实模型输出不符合结构要求时阻塞，不自动重复调用。
2. 目录须是 A 电脑上明确给出的现存项目目录，不能用整盘、网络根或链接扩大访问范围。缺依赖应明确报告；软件不替用户扩大权限。
3. 实际文件系统边界依赖本机 Codex 沙盒组件可用。已验证配置被接受，未在本轮运行真实工具越界用例。
4. 历史超过输入限制时明确报错要求整理，不静默截掉约束；本版没有自动压缩长对话功能。
5. 快照继续排除常见凭据、版本控制目录和缓存；排除规则不能识别写入普通源码的所有秘密。源码完整性以清单和排除项为准。
6. 真实 B、真实 SMB 中断、跨机权限及恢复验收未执行。B 必须核对快照哈希、给出实际读文件/测试证据，不能以 A 的本机模拟替代。

## 升级与使用

1. 结束或保存正在执行的旧任务，分别关闭 A/B 的旧程序。两端均解压 0.3.17 至新目录，运行 `AgentLink.exe`；保留 0.3.16 目录用于回退。
2. 沿用各自本机设置、账号和原共享通信目录；不用复制另一台的登录配置。不会自动替换运行中的旧 EXE。
3. A 在输入框写任务与目录，等待澄清和任务说明，再回复“开始”。B 此时可离线；就绪后接回已确认任务。
4. 运行中直接在本机主输入框补充要求；额度恢复后输入“继续”。恢复不重置额度，且可能发送一次新的模型请求。
5. 旧版记录可查看和导出。旧任务如需进入新统一流程，在 A 新建对话并粘贴需要承接的材料；**未承诺旧版未完成任务原地自动迁移**。0.3.17 新对话也没有验证可由 0.3.16 续跑。
6. 回退仅指重新运行保留的旧程序；不要让旧版和新版同时执行同一任务，也不要为回退删除新记录。需要真实生产数据迁移时先做数据备份并单独验证。

开发行动、修订、首次失败和最终交付过程见 [完整开发日志](DEVELOPMENT-LOG-0.3.17.md)。
