## 使用

两台电脑退出旧版后，都使用本版 AgentLink.exe；B 可复制 ZIP 后解压运行。保留原数据目录、项目绑定及本机 Codex 登录配置，重新连接同一共享目录。B 审查本版源码时，A 项目目录选择本版的 source 子目录。

旧版无序号且时间完全相同的消息无法追溯真实先后；缺失或损坏的恢复记录不会自动补造。长路径修复覆盖已确认位置，不代表所有外部工具和 UNC 路径均已验证。
