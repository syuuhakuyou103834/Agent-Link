## 第 6 项归因

- 环境：本机 LongPathsEnabled=0；普通 Python 操作超长路径会失败。没有修改注册表、ACL 或系统权限。
- 产品：长路径目录创建、claim，以及恢复时普通路径与扩展路径比较，都已本机复现并修复。
- 测试夹具：原 test_intervention.py 直接写超长 B 快照路径，注入篡改时先报 FileNotFoundError。改为通过 io_path 写入，使测试实际检验快照校验。
- 清理夹具：新增长路径测试修复后，断言通过但 TemporaryDirectory 清理出现 WinError 145。先验证清理对象位于本次隔离测试根目录内，再用扩展路径清理。06-after.log 保留首次清理错误，06-after-fixture.log 及最终日志通过。这不证明历史 A/B 的全部 WinError 145 都有同一原因。
